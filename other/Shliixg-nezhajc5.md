# `nezhajc5.sh` 脚本分析

脚本来源：`/private/tmp/Shliixg/nezhajc5.sh`

## 一句话结论

这是一个只读的 `Incus/LXC` 安全检测脚本，专门用来扫描“小鸡”里是否存在和哪吒 agent 被黑相关的特征。它不修改配置、不杀进程、不删除文件，只做审计和告警。

## 主要作用

- 扫描 Incus/LXC 容器列表
- 识别是否安装或运行 `nezha-agent`
- 检测可疑进程、临时文件、启动项、cron、`ld.so.preload`
- 统计公网连接数量和远端 IP 数
- 输出风险报告到 `/root/`

## 核心特征

### 1. 只读检测

脚本开头就明确说明：

- 不删除
- 不杀进程
- 不修改配置

这让它适合做排查工具，而不是修复工具。

### 2. 专门针对哪吒 agent 被黑场景

它重点查这些内容：

- `nezha-agent`
- `/opt/nezha`
- `/etc/nezha`
- 可疑脚本名
- 可疑 IP
- 可疑 cron / 启动项
- `ld.so.preload`

### 3. 结合公网连接数做辅助判定

它还会统计容器内公网连接数和公网远端 IP 数。
如果数量超过阈值，就会加重风险判定。

### 4. 支持参数

常用参数包括：

- `--nezha-only`
- `--quiet-ok`
- `--show-ok`
- `--no-color`

## 适合什么场景

- 你有一批 Incus/LXC 小鸡
- 想快速筛查哪吒 agent 被黑痕迹
- 想做安全巡检和出报告

## 备注

- 这是仓库里最独立的一类脚本，和 `sing-box` 管理脚本不是一回事。
- 它更像安全排查工具，而不是代理部署工具。
