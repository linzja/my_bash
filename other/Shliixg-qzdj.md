# `qzdj.sh` 脚本分析

脚本来源：`/private/tmp/Shliixg/qzdj.sh`

## 一句话结论

这是一个较早期、较轻量的 `sing-box` 全局透明出口代理部署脚本。它的目标是把服务器流量接到 `sing-box` 上，通过 `TUN` 接口和路由规则实现“全局代理”或“分流代理”。

## 主要作用

- 一键部署 `sing-box`
- 重新配置代理节点
- 查看运行状态和外网出口
- 卸载 `sing-box` 和相关服务
- 生成 keep-alive 保活脚本

## 核心流程

### 1. 交互式选项

脚本启动后给 4 个入口：

- 一键部署 / 重新配置
- 重新安装 `sing-box` 核心
- 查看状态
- 停止并卸载

### 2. 节点类型较少

它只支持这几类出站：

- `SOCKS5`
- `Shadowsocks`
- `VLESS` 明文 TCP

这说明它更偏向“透明转发”和“简单代理接入”，不是大而全的协议管理面板。

### 3. 透明代理方式

它会：

- 创建 `tun0`
- 写 `sing-box` 配置
- 设置 `keep-alive` 服务
- 通过 `ip rule` 和 `iptables` 做路由保活

这是典型的“把整机流量导进代理”的做法。

### 4. 分流规则

脚本内置了不少直连规则，例如：

- GitHub
- Docker
- Debian / Ubuntu / Alpine
- 常见语言生态站点
- 常见 CDN

也就是说，它不是纯全局代理，默认更偏“常用站点直连，其余走代理”。

## 适合什么场景

- 单台机器做透明代理出口
- 需要简单的全局代理部署
- 想要可视化查看出口 IP
- 主要用 `SOCKS5`、`SS`、`VLESS` 的基础方案

## 备注

- 这个脚本比后面的 `xldj.sh / 66.sh / 3.sh` 简单很多。
- 它更像 `sing-box` 的透明出口部署器，而不是完整代理面板。
